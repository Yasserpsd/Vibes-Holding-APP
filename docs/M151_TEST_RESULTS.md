# M151 — نتائج اختبار قراءة ملفات PDF (عبر التطبيق → الهب → n8n)

كل تشغيل يرسل ملف PDF حقيقيًا من حساب الأدمن عبر `POST /api/advisor/file` ثم `poll` حتى وصول الرد (`server/scripts/m151-file.mjs`). الملف التجريبي `server/scripts/m151-sample.pdf`: دراسة جدوى خيالية لمطبخ سحابي فيها خلل واضح (تكلفة اكتساب العميل 180 ريالًا مقابل هامش 9.9 ريال للطلب، ورصيد يكفي ثلاثة أشهر).

_لم يُشغَّل بعد: ينتظر تركيب الهب 2.23.0 على vcmem، ونشر مسودة n8n، ودفع السيرفر إلى Railway (2026-10-29)._
